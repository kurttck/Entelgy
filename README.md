# Descripción:

Se implementó la creacion de objetos de animales con la funcionalidad de onomatopeyas y mostrar el tipo de animal que es.

# Ejecución:

Primero ejecutamos: 
``` console
mvn clean package 
 ```

luego ingresaremos lo siguiente(los datos de animales puede variar):

``` console
java -jar target/PruebaEntelgy-1.0.jar "caballo|terrestre|hiii" "rana|acuatico|croac" "mosquito|volador|bzz"
```
